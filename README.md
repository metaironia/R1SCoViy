# R1SCoViy

R1SCoViy — Симулятор процессора **RISC-V** с поддержкой следующих расширений:
- **RV32I** — базовый целочисленный набор инструкций
- **RV32M** — инструкции умножения и деления
- **RV32F** — инструкции арифметики с плавающей точкой (одинарная точность)
- **RV32Zbb** — расширения базовых битовых операций

R1SCoViy исполняет **ELF-файлы**,, скомпилированные для архитектуры `rv32imf_zbb` с ABI `ilp32`, использующие системные вызовы `read`, `write` и `exit` из api/api.s. Никакие другие системные вызовы не поддерживаются.

## Структура проекта

```
├── CMakeLists.txt          # Файл конфигурации CMake
├── src/
│   ├── main.cpp            # Точка входа симулятора

│   └── LogHelper/          # Модуль логирования
├── tests/                  # Тестовые программы
└── api/                    # API для системных вызовов
```

## Сборка проекта

Для сборки проекта требуется **CMake** версии 3.13 или выше и компилятор с поддержкой C++17.

Сборка:
```bash
git clone https://github.com/metaironia/R1SCoViy
cd R1SCoViy
mkdir build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make
```

После сборки исполняемый файл `r1scoviy` будет находиться в папке `build`. 

Также можно включить дебажные логи, так как по умолчанию они выключены. Для включения замените значение опции -DCMAKE_BUILD_TYPE с Release на Debug.

### Как получить совместимый код

Для создания программ, которые может исполнять симулятор, необходимо использовать `riscv64-unknown-elf`.

#### 1. Установка toolkit'a

```bash
sudo apt install gcc-riscv64-unknown-elf
```

#### 2. Линковка с API для системных вызовов

R1SCoViy поддерживает три системных вызова:
- `read` (63) — чтение из файлового дескриптора
- `write` (64) — запись в файловый дескриптор
- `exit` (93) — завершение программы

в папке api лежит файл api.s, который содержит в себе определения этих трех системных вызовов. Чтобы скомпилировать api.s, пропишите в консоль:

```bash
riscv64-unknown-elf-as -mabi=ilp32 -march=rv32imf_zbb api.s -o api.o
```

Чтобы слинковать с вашей программой на C, пропишите в консоль:
```bash
riscv64-unknown-elf-gcc -mabi=ilp32 -march=rv32imf_zbb -nostartfiles -nostdlib -static api.o <имя_программы.c> -o <имя_исполняемого_файла>
```

## Запуск симулятора

Для запуска симулятора передайте имя ELF-файла в качестве аргумента:

```bash
./r1scoviy <имя_файла> [аргументы_командной_строки]
```

Также опционально можно передать аргументы командной строки. Тогда Это будет аргументами командной строки, которые принимает ваша программа на C.
